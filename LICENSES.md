# Data source license ledger

A source is added here before any of its data is ingested. "Commercial use" must be yes, or the source stays in research-only experiments and out of the product.

| Source | Content | License / terms | Commercial use | Redistribute text | Notes |
|---|---|---|---|---|---|
| DailyMed (NLM) | US drug labels (SPL XML) | US government work, public domain | Yes | Yes | Verify per-label third-party content |
| ClinicalTrials.gov | Trial records | Public domain, NLM terms of use | Yes | Yes | |
| openFDA | Labels, adverse events, recalls | Public domain (CC0) | Yes | Yes | Not for clinical use disclaimer |
| CMS Medicare Coverage Database | NCDs / LCDs | Public domain, with AMA CPT notices | Check | Check | CPT code descriptions are AMA-copyrighted |
| PubMed abstracts (NCBI) | Abstracts | NLM terms; some records carry publisher copyright | Check | Link, do not bulk-redistribute | |
| PubMed Central OA | Full text | Commercial-use subset only (CC BY / CC0) | Subset only | Per article license | Do not use the non-commercial subset |
| RxNorm | Drug vocabulary | UMLS license | Check | Check | Free, requires UMLS account |
| MeSH | Vocabulary | Public domain (NLM) | Yes | Yes | |
| UMLS / SNOMED CT | Terminologies | UMLS license, affiliate terms | Check | Restricted | Do not bundle into the repo |

Status values to be confirmed against each source's current terms before use. This file is a working record, not legal advice.
