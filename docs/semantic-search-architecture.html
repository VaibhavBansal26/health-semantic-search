4. Tenancy tiers: one codebase, three isolation levels

Shared tables with row-level security are the safety net, not the isolation strategy. A single 10M-document tenant degrades everyone's index, and one bad migration takes every tenant down. Placement is decided per tenant from size and contract.

Pooled

small tenants · self-serve trial
  • Shared index collection, tenant_id on every row
  • Postgres RLS enforced in the data layer
  • Shared GPU pool with per-tenant quotas
up to ≈ 500k documents per tenant

Dedicated collection

mid-market · paid
  • Own index collection and Postgres schema in a shared cell
  • Independent re-embed and blue/green index flips
  • Noisy-neighbour risk limited to compute, not index quality
≈ 500k – 10M documents

Dedicated cell

enterprise · regulated · on-prem
  • Whole data-plane cell per tenant: their region, their VPC, or their racks
  • Same Helm/Terraform artifact as SaaS cells; N-1 version skew supported
  • BYOK encryption, local LLM, telemetry opt-in
10M+ documents or any residency requirement

5. Decisions locked at the first commit

Each of these is cheap on day one and a multi-month rewrite later.

DecisionChoiceWhy it cannot be retrofitted
Tenant and ACL modeltenant_id everywhere; principals on the document; identity graph as a serviceEvery query, index and cache key depends on it. Adding it later means re-indexing every tenant.
Index engineFiltered HNSW + BM25 in one engine (Vespa, Qdrant); int8 or binary with rescoringMoving vectors between engines is a full re-embed at GPU cost.
Embedding versioningmodel_version on every vector; blue/green indexes with shadow evalWithout it, the first model upgrade is an outage or a silent quality regression.
Ingestion runtimeDurable workflows (Temporal) with checkpointed cursors and idempotent upsertsTask queues lose state mid-backfill; recovering a 10M-file sync by hand is not an option.
ObservabilitySelf-hosted in the cell, content redacted by default, per-tenant retentionTraces carry query text and chunks; a third-party tracing SaaS is a data-handling clause you cannot sign.
ErasureOne pipeline covering index, Postgres, caches, traces and backupsGDPR deletion requests arrive before you have time to find every copy.
Cache keyingTenant + normalised query + hash of the permitted result setAny answer cached across users is a cross-user data leak.

Deferred on purpose

GraphRAG, multimodal retrieval, agentic multi-step search and a browser extension are all out of v1. None of them closes a deal; permission correctness, three production-grade connectors and sub-second results do. Agentic tool use in particular waits until the retrieved-text-is-data boundary in the LLM gateway exists, because any employee who can edit a wiki page can otherwise write instructions into the model's context.
